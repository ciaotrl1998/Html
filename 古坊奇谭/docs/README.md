# 古坊奇谭

根据同目录的《古坊奇谭_策划文档.md》制作的可玩 HTML 原型：白天经营中国古镇，夜间自动塔防。

## 启动

**直接用 Chrome、Edge、Firefox 或 Safari 打开 `dist/古坊奇谭.html` 即可游玩。** 这是可独立分享的离线单文件，不需要安装依赖、不需要服务器，也不会请求外部图片、字体或接口。

也可以打开根目录的 `index.html`，此时需保留 `css/`、`js/` 目录。开发时首次执行 `npm install`，修改源码后执行 `npm run build`，同时更新兼容运行脚本和单文件版本。两个入口在浏览器中可能使用不同的本地存档空间，可通过导出/导入迁移进度。

手机可通过静态网页服务器访问整个目录，也可将目录放到任意静态网站空间。没有后端服务。

## 操作

- 点击空地：打开建造栏，点击建筑卡片直接建造。切换产业、防御、民生或神庙页签后，选择其他地格或重新打开游戏仍保持该页签。不可建卡片会标注原因。
- 点击建筑：查看属性、升级或拆除。祠堂不能拆除。
- 拖动地图移动视角；鼠标滚轮或双指缩放。
- 底部卡片横向滑动，电脑也可以按住拖动。
- 时间右侧 `Ⅱ` 暂停并打开菜单，关闭菜单或点击“继续游戏”恢复。固定 1 倍速，无加速按钮。空格打开/关闭暂停菜单，Esc 关闭菜单或建筑面板。
- 夜间点击右下角神技按钮施法。箭塔、擂石台和兵营自动攻击；建造、升级和拆除在白天与夜晚使用同一规则。
- 暂停菜单提供音效、保存进度、存档导入导出和重新开始。

主画面按顺序显示铜钱、工材、香火，另有时间和一个暂停菜单按钮；建筑面板与神技按需出现。电脑也显示居中的手机竖屏，不显示教程卡片、玩法提示、视角控制按钮或地形网格。

## 已实现

- 17×17 固定地形地图，包含平地、水岸、水域、林地和山地。水岸由水域外围八向相邻的地格形成，有独立的浅沙色外观；水域禁止建造任何建筑，农田可建在水岸，或与水井相邻 1 格的平地。林地的产业建筑仅可建桑园，山地的产业建筑仅可建石场，其余产业向平地或水岸延伸；防御、民生和神庙不受这条限制。相邻含斜角（对角格距离按 1 计）。
- 非水岸农田失去最后一口相邻水井后，每秒损失最大耐久的 5%，期间不受白天自动修复；耐久耗尽即被摧毁。补建水井可停止掉耐久，水岸农田不受影响。
- 读取旧存档时，原先建在水中的建筑会迁往最近的空闲陆地，农田优先迁到水岸，等级和资源进度保留；如所有可用地格已满，则保留原建筑并提示。
- 全部 26 类建筑：四条三段产业链、两栋终极建筑、防御/民生/神庙建筑。祠堂最高 Lv.15，其他建筑最高 Lv.9；祠堂唯一，其余 25 类可建造。
- 八向相邻前置、等级传递、Lv.1–9 数值升级；普通建筑 Lv.2/3/4/5/6/7/8/9 分别要求祠堂达到 Lv.2/3/5/7/9/11/13/15。普通建筑 Lv.1–3、4–6、7–9 分别复用一、二、三阶段外观。建成后不再依赖前置存活。
- 点开已建建筑时，仅显示它与前后相差一级的产业建筑之间的淡色直虚线；终极建筑只连指定的产业终点。范围框只对范围大于 0 的产业建筑、水井和民居显示。关闭详情后关系线与范围框消失。
- 每种产业建筑有建造范围（茶肆/石场 1，农田/桑园 0，磨坊/织坊 1，客栈/瓷窑 2，钱庄 3，酒坊/成衣铺 2，商号 3，汇财会馆/百工院 4）：范围内不可再建相同建筑；范围内只有直接前一级产业按 `+10% × 2^(前置等级−1)` 提供收入增益，跨两级无加成。两座终极建筑只受各自指定的终点建筑增益。
- 产业有数量上限：农田、桑园各 9 座，茶肆、石场各 6 座，中段各 4 座，终点各 2 座，汇财会馆、百工院各 1 座。建造卡会显示当前数量与上限。
- 汇财会馆必须紧邻钱庄与酒坊，生产铜钱并使全镇铜钱收入 +5%；百工院必须紧邻成衣铺与商号，生产工材并使全镇工材收入 +10%。建造前置建筑 Lv.1 即可；终极建筑升级时，两种指定前置都必须达到目标等级。
- 商链、农链产铜钱；丝链、工链产工材。工材使用与古坊配色一致的锤子图标。建造和升级按对应的铜钱、工材成本扣费；链起点只用一种资源，中后段逐渐加入另一种资源。普通建筑 Lv.N 升 Lv.N+1 的费用为对应建造费用 × 1.8 × 2.15^(N−1)，分别向上取整；祠堂以 120 铜钱、90 工材为基价并按每级 ×1.65 增长。
- 民居、水井、戏台、集市加成；每栋建筑每满 1 秒结算一次铜钱或工材及香火，建成后独立计时。
- 建筑卡片和详情把每秒产出拆为基础值与绿色加成，例如“铜钱 +10（+3）/秒”或“工材 +5（+1）/秒”；数值四舍五入、最多保留一位小数，加成为 0 或显示时舍入为 0 则省略括号。
- 每次结算在对应建筑上方显示“+数额＋资源图标”，向上飘动并淡出。小数收益保留到后续结算，飘字整数与实际到账一致。
- 白昼 72 秒、黄昏 8 秒、夜间清完波次后入晓；白天每秒修复 10% 最大耐久。
- 加权格子寻路、绕开水域与拆墙、建筑受损及毁坏、三类敌人、民兵、减速、远程与范围攻击；受损建筑的血条贴近图标上方。敌人耐久每夜 ×1.23、伤害每夜 ×1.12、移速逐夜增加且最高为基础的 1.22 倍；波次数量从首夜 10 个快速增加，最高 120 个，最低生成间隔 0.28 秒。
- 驱鬼符、回春诀、道观解锁天雷；香火成本与冷却。
- 擂石台、兵营、道观按资源建造，无数值解锁门槛；保留发展成就奖励，不显示引导任务；每 7 日灯会、收益加成与妖将来袭。
- 祠堂失守结束游戏；守过第七夜展示阶段胜利，可继续经营。
- 本地自动存档、存档校验、导入导出；页面隐藏和打开菜单时暂停计时。无离线收益。
- 自绘 Canvas 中式建筑与地形、昼夜色调、弹道及神技效果、可选合成音效。

## 原型数值约定

初始资源为 200 铜钱、120 工材、25 香火；商链和农链各段基础收入为 1/3/6 钱每秒，丝链和工链为 2/5/9 工材每秒，祠堂基础收入 0.4 钱与 0.25 香火每秒。每级产出、攻击、香火和辅助增益为上一级的 2 倍，耐久为上一级的 1.55 倍；产业加成总量上限 +200%，每七日灯会另外提高当日收入 25%。驱鬼符定身全部来敌 4 秒并造成 20 伤害；回春诀修复全部建筑 35%；天雷全图造成 240 伤害，对阴兵造成 350。

两座终极建筑分别要求相邻指定的一对产业终点，Lv.1 即可；相邻含斜角。

地图完整开放，扩张通过继续占用地块进行。`node scripts/balance-sim.js 15` 可重跑抢建产业、产业优先升级、兼顾防守三条固定路线；自动化回归还会用 5 个种子验证主动防守路线。当前基线中，无视防守会在第 2 夜失守，主动发展、升级与施法可稳定守过第 15 夜，但不保证继续无损推进。

## 文件与验证

目录结构：

```
古坊奇谭/
  index.html          开发入口，引用 css/ 与 js/
  css/style.css       样式
  js/game.js          独立游戏逻辑
  js/art.js           绘图
  js/app.js           操作、界面和存档
  js/boot.js          安卓兼容布局与启动错误反馈
  js/runtime.js       build.js 生成的兼容运行脚本
  dist/古坊奇谭.html  可独立分享的离线单文件
  docs/               策划文档与说明
  tests/              规则测试与浏览器回归测试
```

`build.js` 通过 esbuild 将脚本转换为 ES2017，生成 `js/runtime.js` 和 `dist/古坊奇谭.html`。规则测试不依赖浏览器：

```sh
node --test tests/game.test.js
```

浏览器回归测试使用 Playwright，验证电脑与手机布局、真实鼠标点击、触摸缩放、建造升级、存档和夜战神技：

```sh
npm install
npm run test:browser
```

浏览器测试默认使用 Windows 标准位置安装的 Chrome，可通过 `CHROME_PATH` 指定浏览器可执行文件。截图默认写入系统临时目录的 `gufang-screenshots`，可通过 `GUFANG_SHOTS` 修改。测试会使用独立浏览器上下文，不操作玩家的真实存档。

### 安卓白屏修复

旧版容器只有 `height: 100dvh`，且子元素全为绝对定位。在不支持 `dvh` 的安卓浏览器中，该声明失效后容器高度变为 0，`overflow: hidden` 会裁掉整个地图和界面。已在浏览器模拟中复现这一情况。

现在采用 `100vh` 后备高度，并由兼容启动脚本使用可视区域的像素尺寸设置容器；相机和触控使用容器内坐标。移除了原生 `dialog.showModal()`、`Object.hasOwn()` 和 `Blob.text()` 依赖，运行脚本转为 ES2017。自动测试覆盖不支持 `dvh`、无 `visualViewport`、无原生 dialog 和旧存档迁移的组合环境。这里是兼容性模拟验证，并非在用户的安卓真机上测试。

存档仅存在当前浏览器中。移动文件路径、清除浏览器数据或更换设备前，建议通过菜单导出 JSON 备份；导入成功会覆盖当前进度，并尽力在本地保留导入前备份。

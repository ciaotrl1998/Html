# 《古坊奇谭》策划文档

**版本：首版原型**
**类型：2D俯视角模拟经营 + 夜间塔防**
**平台：手机竖屏**
**核心参考：猛鬼宿舍**
**背景：中国古代村镇**

---

## 一、游戏概述

玩家在一块由格子构成的古代地图上发展产业、建造防御，白天经营建造，夜晚抵御妖鬼山匪。目标是从一座祠堂发展成热闹古镇。

- 地图由格子构成，2D俯视角。
- 点击空格子，底部弹出建筑列表。
- 点击已建建筑，底部弹出或切换为建筑详情，可升级或拆除。
- 底部栏高度要一致，需要是盖在地图上，而不是和地图同层级，放置弹出底部栏挤压地图。
- 防御与修复全自动，玩家只负责建造与升级。
- 神技手动释放，作为唯一的战斗操作。
- 玩家可以单指或双指拖拽移动视角，双指可放大或缩小视角。也需要兼容电脑鼠标的操作，按住拖动视角，滚轮放大缩小。
- 美术为中式美学的设计。
---

## 二、核心循环

白天，玩家负责建造、升级、摆位；系统让受损建筑自动回血。

黄昏，玩家简单布防；系统提示今夜来袭方向。

夜晚，神技按钮出现，玩家可点神技；建筑自动攻击，妖鬼进攻。建造、升级和拆除与白天规则相同。

每7天，触发节日事件与强敌来袭。

长期目标：完善产业链，积累铜钱与工材，抵御更强来袭，扩建聚落。

---

## 三、资源

游戏使用三种资源，界面按铜钱、工材、香火排列。

**铜钱**
- 用途：建造、升级。
- 来源：商链、农链与部分终极建筑自动产出，完成坊志和守夜也可获得。

**工材**
- 用途：建造、升级，与铜钱并列；图标是一把符合古坊画风的小锤子。
- 来源：丝链、工链自动产出，不再由这两条产业链产铜钱。

**香火**
- 用途：释放神技。
- 来源：神庙类建筑产出。

商链、农链以工材为主要建造耗材；丝链、工链以铜钱为主要建造耗材。茶肆、农田只耗工材，桑园、石场只耗铜钱。中段和终点建筑逐渐加入另一种资源：桑园只用铜钱，织坊用较多铜钱和少量工材，成衣铺用更多铜钱和中量工材。每栋建筑独立计时，每满 1 秒结算产出。

## 四、地图与地形

### 4.1 五种地形

**平地**
- 外观：黄土、青草。
- 允许建造：所有建筑；农田需与水井相邻 1 格。

**水域**
- 外观：河流、池塘。
- 不允许建造任何建筑。

**水岸**
- 外观：环绕水域的浅沙色岸线。
- 由水域外围八方向相邻的平地自动生成，斜角也算相邻。
- 允许建造：所有建筑；农田可直接建于此。

**林地**
- 外观：竹林、树林。
- 产业建筑只允许桑园；防御、辅助和神庙建筑仍可建造。

**山地**
- 外观：石头、丘陵。
- 产业建筑只允许石场；防御、辅助和神庙建筑仍可建造。

### 4.2 地形限制规则

水域禁止所有建筑。林地只允许桑园这一种产业建筑，山地只允许石场这一种产业建筑；后续产业建筑应向平地或水岸延伸，并与前一级建筑相邻。防御、辅助和神庙建筑不受林地、山地的产业限制。

- 茶肆：平地。
- 农田：水岸，或与水井相邻 1 格的平地（含斜角）。
- 桑园：林地。
- 石场：山地。
- 其他产业建筑：只可建于平地或水岸，仍须满足前置条件。
- 防御、辅助和神庙建筑：任意非水域地形。

### 4.3 地图生成规则

1. 水域、林地、山地至少成片 3×3，不做散点；水岸围绕水域生成。
2. 主基地祠堂周围保证有平地，且能看到一到两种资源地形。
3. 资源地形旁留出开阔平地，供经济链向内延伸。
4. 首版不做地形改造，地形固定。

## 五、经济链系统

### 5.1 四条经济链

**商链**
- 起点：茶肆（平地）。
- 中段：客栈。
- 终点：钱庄。

**农链**
- 起点：农田（水岸或水井旁平地）。
- 中段：磨坊。
- 终点：酒坊。

**丝链**
- 起点：桑园（林地）。
- 中段：织坊。
- 终点：成衣铺。

**工链**
- 起点：石场（山地）。
- 中段：瓷窑。
- 终点：商号。

说明：

- **起点建筑**：受地形限制，是这条链的入口。
- **中段建筑**：任意地形，但必须与起点建筑相邻。
- **终点建筑**：任意地形，但必须与中段建筑相邻。

### 5.2 相邻规则

- 上下左右以及斜向算八个方向。
- 建成后不再检查前置关系，前置被拆或降级不影响已建建筑。

### 5.3 玩家认知

玩家只需记住一句话：

> 起点看地形，后面挨着建。

地图上会把同一条链的建筑用淡色虚线连起来，方便一眼辨认。

## 六、建筑升级系统

### 6.1 基本规则

- 每栋建筑拥有 Lv1 至 Lv3 三个等级。
- 升级只改变数值与外观，不改变位置和功能。
- 升级需要满足两个条件：对应铜钱、工材足够，前置建筑等级足够。
- Lv1 升 Lv2 的资源费用分别为建造费用的 1.5 倍，Lv2 升 Lv3 为 2.25 倍，各项向上取整。起点建筑升级始终只耗其建造所用的一种资源。

### 6.2 等级传递规则

> 一栋建筑要升到 LvN，其相邻前置建筑必须大于或等于 LvN。

- 多个前置时，取其中最高等级计算。
- 起点建筑没有前置，付清对应资源即可升级。
- 中段建筑升级，要求相邻起点建筑等级大于或等于目标等级。
- 终点建筑升级，要求相邻中段建筑等级大于或等于目标等级。

示例：

- 客栈升 Lv2：相邻茶肆需大于或等于 Lv2。
- 钱庄升 Lv3：相邻客栈需大于或等于 Lv3。
- 客栈升 Lv3：相邻茶肆需大于或等于 Lv3，或旁边有另一个茶肆 Lv3。

玩家想拉高终点建筑，就必须把整条链一起升上去。

### 6.3 升级收益

- 每升一级，产出、血量、攻击力按固定倍率提升。
- 升级后建筑改名换外观，视觉上有明显变化。

## 七、终极建筑

### 7.1 定位

终极建筑是平衡发展的奖励，鼓励玩家不要只深耕一条链。

首版做两栋。

**汇财会馆（铜钱终极）**
- 前置：必须同时紧邻钱庄、酒坊。
- 造价：300 铜钱、420 工材，以工材为主。
- 基础产出：26 铜钱／秒。
- 光环：全镇铜钱收入 +5%。

**百工院（工材终极）**
- 前置：必须同时紧邻成衣铺、商号。
- 造价：620 铜钱、340 工材，以铜钱为主。
- 基础产出：39 工材／秒。
- 光环：全镇工材收入 +10%。

### 7.2 判定规则

- 八方向相邻，包括斜角。
- 必须分别具备该建筑指定的两种终点；其他终点不能替代。
- 不看等级，指定终点建筑 Lv1 也算。
- 建成后不再检查，后续拆除不影响。

### 7.3 布局示意

汇财会馆，相邻钱庄与酒坊：

```
┌──┬──┬──┐
│  │酒│  │
├──┼──┼──┤
│  │汇│钱│
├──┼──┼──┤
│  │  │  │
└──┴──┴──┘
```

百工院，相邻成衣铺与商号：

```
┌──┬──┬──┐
│  │成│  │
├──┼──┼──┤
│商│工│  │
├──┼──┼──┤
│  │  │  │
└──┴──┴──┘
```

### 7.4 设计意图

- 只堆一条链：收入高，但建不了终极建筑，上限封死。
- 发展商链与农链：可建汇财会馆，增强铜钱经济。
- 发展丝链与工链：可建百工院，增强工材经济。

只有奖励缺席，没有惩罚。玩家想突破天花板，自然会回头补齐其他链。

## 八、自由建筑

以下建筑不受地形限制，也不受经济链限制，可任意建造。

### 8.1 防御类

- 木栅：阻挡敌人，血厚。
- 箭塔：单体远程攻击。
- 擂石台：范围伤害，攻击慢。
- 兵营：夜晚自动派出民兵。

### 8.2 辅助类

- 民居：相邻经济建筑产出加 10%。
- 水井：相邻 1 格的平地可建农田，并使相邻农田产出加 20%。若非水岸农田失去最后一口相邻水井，每秒损失最大耐久的 5%，期间不受白天自动修复，耐久归零后摧毁；补建水井可停止掉耐久。水岸农田不受此影响。
- 戏台：全局产业收入小幅提升，包括铜钱与工材。
- 集市：小范围内所有建筑收入加 5%。

### 8.3 神庙类

- 祠堂：主基地，被摧毁则游戏结束。
- 土地庙：产出香火。
- 钟馗像：周围妖鬼减速。
- 道观：产出香火，解锁天雷神技。

## 九、战斗与修复

### 9.1 战斗

- 夜晚妖鬼从地图边缘随机方向出来往祠堂进攻，不能穿越水域。
- 需要有基于格子的寻路系统，敌人会从最短路线进攻。
- 建筑如果阻挡了路线，敌人会攻击该建筑。
- 防御建筑自动攻击，玩家无需操作。
- 玩家可点右下角神技按钮，消耗香火释放天雷、驱鬼、修复等技能。

### 9.2 修复

- 白天受损建筑每秒回复 10% 最大耐久，约 10 秒可从低耐久恢复到满值；缺水农田除外。
- 夜晚不回血。
- 血量归零的建筑彻底毁坏并消失，格子空出，需要重新建造。
- 祠堂血量归零则游戏结束。

### 9.3 敌人类型（首版）

- 山匪：数量多，攻低，被木栅、箭塔克制。
- 阴兵：血厚，减速抗性，被钟馗像、道观克制。
- 妖狐：速度快，绕路，被擂石台、兵营克制。

- 可建：亮色，点一下直接建，无标签。

- 前置等级不足：灰显，标签如「需邻茶肆Lv2」。
- 钱不够：半亮，价格红字，标签如「差 50 钱」。
- 夜晚建筑操作与白天一致：可建造、升级和拆除，仍按地形、资源及前置条件判定。

## 十一、建筑总览

**经济链起点**（4 个）：茶肆、农田、桑园、石场。

**经济链中段**（4 个）：客栈、磨坊、织坊、瓷窑。

**经济链终点**（4 个）：钱庄、酒坊、成衣铺、商号。

**终极建筑**（2 个）：汇财会馆、百工院。

**防御类**（4 个）：木栅、箭塔、擂石台、兵营。

**辅助类**（4 个）：民居、水井、戏台、集市。

**神庙类**（4 个）：祠堂、土地庙、钟馗像、道观。

建筑合计 26 栋。其中 24 栋可升 Lv1 至 Lv3，视觉总量约 72 种；2 栋终极建筑为单级。玩家需要记住的核心规则只有一条：起点看地形，后面挨着建，升级跟着前置走。

## 十二、操作流程总览

```
点空格子
   ↓
底部面板滑出，自动定位到可建的经济链
   ↓
可建卡片点亮 → 点一下 → 直接建成
灰卡片抖一下 → 不打断操作
   ↓
点已建建筑 → 升级 / 拆除
   ↓
夜晚妖鬼来袭 → 建筑自动战斗，白天自动修复
   ↓
香火足够 → 点右下角释放神技
```

## 十三、首版开发优先级

**P0**
- 格子地图、点击建造、铜钱／工材／香火三种资源、白天自动修复。
- 四条经济链、相邻规则、升级传递规则。

**P1**
- 防御建筑、夜晚波次、神技。
- 终极建筑汇财会馆与百工院。

**P2**
- 节日事件、更多敌人、更多产业组合。

**P3**
- 美术升级、建筑外观细化、音效。

以上为首版策划文档。核心设计原则贯穿始终：规则少、认知轻、奖励多、惩罚少。玩家只需要理解「起点看地形，后面挨着建，升级跟着前置走」，就能顺畅体验全部内容。

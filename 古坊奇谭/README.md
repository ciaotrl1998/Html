# 古坊奇谭

根据同目录的《古坊奇谭_策划文档.md》制作的可玩 HTML 原型：白天经营中国古镇，夜间自动塔防。

## 启动

**直接用 Chrome、Edge、Firefox 或 Safari 打开 `古坊奇谭.html` 即可游玩。** 这是可独立分享的离线单文件，不需要安装依赖、不需要服务器，也不会请求外部图片、字体或接口。

也可以打开 `index.html`，此时需保留 `style.css`、`boot.js`、`runtime.js` 在同一目录。开发时首次执行 `npm install`，修改源码后执行 `npm run build`，同时更新兼容运行脚本和单文件版本。两个入口在浏览器中可能使用不同的本地存档空间，可通过导出/导入迁移进度。

手机可通过静态网页服务器访问整个目录，也可将目录放到任意静态网站空间。没有后端服务。

## 操作

- 点击空地：打开建造栏，点击建筑卡片直接建造。切换产业、防御、民生或神庙页签后，选择其他地格或重新打开游戏仍保持该页签。不可建卡片会标注原因。
- 点击建筑：查看属性、升级或拆除。祠堂不能拆除。
- 拖动地图移动视角；鼠标滚轮或双指缩放。
- 底部卡片横向滑动，电脑也可以按住拖动。
- 时间右侧 `Ⅱ` 暂停并打开菜单，关闭菜单或点击“继续游戏”恢复。固定 1 倍速，无加速按钮。空格打开/关闭暂停菜单，Esc 关闭菜单或建筑面板。
- 夜间点击右下角神技按钮施法。箭塔、擂石台和兵营自动攻击；夜晚停止建造、升级和拆除，黄昏仍可布防。
- 暂停菜单提供音效、保存进度、存档导入导出和重新开始。

主画面只保留铜钱、香火、繁荣、时间和一个暂停菜单按钮；建筑面板与神技按需出现。电脑也显示居中的手机竖屏，不显示教程卡片、玩法提示、视角控制按钮或地形网格。

## 已实现

- 17×17 固定地形地图，包含成片平地、水域、林地和山地。农田只能建在与水域上下左右相邻的平地，不可直接建在水中。
- 全部 26 类建筑：四条三级产业链、两栋单级终极建筑、防御/民生/神庙建筑。祠堂唯一，其余 25 类可建造。
- 四向相邻前置、等级传递、Lv.1–3 数值与外观升级；建成后不再依赖前置存活。
- 会馆、市舶司按相邻终点**种类**判定，不要求满级；提供全图经济加成。
- 民居、水井、戏台、集市加成；每栋建筑每满 1 秒结算一次铜钱和香火，建成后独立计时。
- 每次铜钱结算在对应建筑上方显示“+数额＋铜币图标”，向上飘动并淡出。小数收益保留到后续结算，飘字整数与实际到账一致。
- 白昼 85 秒、黄昏 12 秒、夜间清完波次后入晓；白天每 2 秒修复 5% 耐久。
- 加权格子寻路、绕行与拆墙、建筑受损及毁坏、三类敌人、民兵、减速、远程与范围攻击。
- 驱鬼符、回春诀、道观解锁天雷；香火成本与冷却。
- 繁荣解锁擂石台、兵营、道观；保留发展成就奖励，不显示引导任务；每 7 日灯会、收益加成与妖将来袭。
- 祠堂失守结束游戏；守过第七夜展示阶段胜利，可继续经营。
- 本地自动存档、存档校验、导入导出；页面隐藏和打开菜单时暂停计时。无离线收益。
- 自绘 Canvas 中式建筑与地形、昼夜色调、弹道及神技效果、可选合成音效。

## 原型数值约定

策划未指定的部分采用便于体验的初始数值：420 铜钱、40 香火；产业各段基础收入为 3/7/13 钱每秒，祠堂基础收入 1 钱与 0.4 香火每秒；每级属性倍率 1.65。辅助建筑的增益随等级线性增加。驱鬼符定身全部来敌 4 秒并造成 20 伤害；回春诀修复全部建筑 35%；天雷全图造成 240 伤害，对阴兵造成 350。

终极建筑遵循策划第七节正文：相邻 2/3 种终点，Lv.1 也算；未采用第 10.5 节示意图中“邻接满级”的冲突文字。

地图完整开放，扩张通过继续占用地块进行。美术为程序绘制的首版风格；建筑数值与长期难度尚可继续调校。

## 文件与验证

`game.js` 为独立游戏逻辑；`art.js` 为绘图；`app.js` 为操作、界面和存档。`build.js` 通过 esbuild 将脚本转换为 ES2017，生成 `runtime.js` 和离线单文件。`boot.js` 提供安卓兼容布局与启动错误反馈。规则测试不依赖浏览器：

```sh
node --test game.test.js
```

浏览器回归测试使用 Playwright，验证电脑与手机布局、真实鼠标点击、触摸缩放、建造升级、存档和夜战神技：

```sh
npm install
npm run test:browser
```

浏览器测试默认使用 Windows 标准位置安装的 Chrome，可通过 `CHROME_PATH` 指定浏览器可执行文件。截图默认写入系统临时目录的 `gufang-screenshots`，可通过 `GUFANG_SHOTS` 修改。测试会使用独立浏览器上下文，不操作玩家的真实存档。

### 安卓白屏修复

旧版容器只有 `height: 100dvh`，且子元素全为绝对定位。在不支持 `dvh` 的安卓浏览器中，该声明失效后容器高度变为 0，`overflow: hidden` 会裁掉整个地图和界面。已在浏览器模拟中复现这一情况。

现在采用 `100vh` 后备高度，并由兼容启动脚本使用可视区域的像素尺寸设置容器；相机和触控使用容器内坐标。移除了原生 `dialog.showModal()`、`Object.hasOwn()` 和 `Blob.text()` 依赖，运行脚本转为 ES2017。自动测试覆盖不支持 `dvh`、无 `visualViewport`、无原生 dialog 和旧存档迁移的组合环境。这里是兼容性模拟验证，并非在用户的安卓真机上测试。

存档仅存在当前浏览器中。移动文件路径、清除浏览器数据或更换设备前，建议通过菜单导出 JSON 备份；导入成功会覆盖当前进度，并尽力在本地保留导入前备份。

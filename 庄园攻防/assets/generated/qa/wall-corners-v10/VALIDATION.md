# 城墙转角修正验证

2026-10-16。旧版只比较连接边的一行／列像素，未检查拐角内部，因此无法阻止用户截图中的墙顶与墙身错位。本轮改为完整剖面拼接和以下回归。

- 5项素材检查：两方向城门原几何、16掩码完整连接臂、全部步道颜色相位与连通性、墙身基线与纵向通道无封口、24张安装文件哈希与二值透明／备份。
- 源码和离线分别检查真实地图76处拐角，涵盖NE／SE／SW／NW四种；646处原生像素抽样覆盖墙顶、转角垛口及墙身，与安装PNG一致。
- 额外8格阶梯路径横跨x=16和y=16的地形缓存分块边界，使用真实`GFArt.render`和真实连接掩码计算，8处中心步道像素均一致。
- 现有门墙回归通过：四个真实城门方向×三个外观阶段、门柱短接头、详情预览、16张墙图和离线自包含加载。
- 损毁城门回归通过：横竖两套残骸、Lv1–15共用、修复后切回完整图、详情刷新，无旧裂缝叠层。
- `npm run test:zoom`和`npm run test:grid`通过：源码／离线、多DPR与七档缩放、近景像素、远景过滤、相机移动、地形缓存与地格对齐均通过回归。

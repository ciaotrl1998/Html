# v10 · 城墙转角修正

修复用户截图中连续阶梯墙的墙顶接缝、垛口偏移和墙身断层。保留v8的灰蓝／米白砖石、箭孔、细深棕描边，以及64×64尺寸和16种连接掩码。

根因：原整理脚本分别缩放每个生成的转角，再覆盖统一边缘条。边界虽能同色连接，内部通道宽度、垛口转折和墙身高度却不一致。

现在由`scripts/wall-autotile.cjs`按统一几何重组已有横、纵直墙的像素材料：

- 墙顶范围固定为纵向x=16..47、横向y=14..41；朝下墙身固定为y=42..53。
- 纵向步道宽14像素，横向投影高8像素；拐角、三通和十字共用同一通道与全局纹样相位。
- 垛口的转角限制在固定角块中，只有真正朝下的封闭边才有墙身；开放的纵向通道不画封口。
- 整个开放连接臂与直墙一致，而非只修最外一行像素。周期整除64，可连续跨瓦片与16格地形缓存分块。

不修改运行时位置、地图形状、建筑、经济、碰撞或战斗规则。无需新生图，也不旋转或拉伸完整转角图。原始生成的16个样本保留在v8源图中，不再拿独立比例的转角主体混拼。

本次修改前的16张运行墙图与旧整理脚本保存在`before/`，原有v8接入前备份亦保留。当前安装图在`assets/tiles/walls/`，更新成品包仍为`../fortifications-v8/fortifications-v8.zip`。

重建：`npm run art:fortifications`。验证：`npm run test:fortifications`，包含新增转角素材与浏览器回归。近景、前后对比和详细记录见[验收说明](../qa/wall-corners-v10/VALIDATION.md)。

# 禾下庄 HTML Demo

直接打开 `index.html` 即可游玩，不需要安装依赖或启动服务。页面引用同目录的 `style.css`、`game.js` 和 `app.js`，不请求外部图片、字体或脚本。

## 试玩内容

- 竖屏格子地图，里正宅、木石采集、工坊、农田、三类养殖棚、堆肥、蛋加工、纺织和织染。
- 点击建造选项，再点击空地放置；有空闲村民时自动指派1人。
- 点击建筑可以调整村民人数、升级、移动或拆除。市场也能指派专职售货村民。
- 村民需要在岗才生产，单人外出暂停生产；物流自动预留物料及接收容量，头顶显示所搬物料。
- 下游无法接收就卖，所有生产输入通过实体物流完成，工坊直接生成数字材料。
- 1～5级建筑与全体村民升级，固定周期上涨租金，首次30秒宽限，买地获胜后可继续经营。
- 暂停、1/2/4倍速、账簿、本地自动存档和重开。

这是单人玩法验证版，未实现真实联机、赠送、多人互助、随机地块和正式音效。动物仅为建筑内动画，不是实体。价格及租金曲线是试玩参数，不代表最终平衡。

开局建议先建伐木场和工坊，建立材料来源，再雇佣村民发展种植、养殖与加工。基础收入会自动到账，但后续租金会持续上涨。

## 验证

运行 `node game.test.js` 检查生产、物流预留、升级、租金及存档规则。`game.js` 的模拟逻辑独立于DOM，方便后续经济模拟和服务端迁移。

存档保存在当前浏览器本地。不同浏览器或某些浏览器的本地文件隔离策略可能不会共享存档；存档不可用时仍可正常试玩。隐藏页面会暂停，不计算离线收益。

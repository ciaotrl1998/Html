固定牌面资源：`00.png`–`51.png`（按梅花、方块、红桃、黑桃，各 2 到 A 排序）以及 `back.png`。
每张 384×558，`display.png` 为顶部、名牌和赢家展示共用的固定字形图集。

游戏与编辑器在进入场景前加载并解码图片，运行时不依赖设备字体生成花色、数字或牌背。
`manifest.json` 记录分辨率与 SHA-256，用于检查打包完整性。

若需重新烘焙，在已安装 Pillow 的 Windows 构建电脑运行：

    python scripts/bake-card-artwork.py

字体只用于离线烘焙，不会随游戏分发，也不会在手机上调用生成脚本。

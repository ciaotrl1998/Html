# 音效素材

`source/` 存放用户提供的原始 MP3 和四段全下 WAV，按下表重命名，归档时保留原始音频内容。
游戏使用 `client/assets/audio/` 中的同名 WAV，格式为 48 kHz、单声道、16 位 PCM。四段全下 WAV 的归档内容与游戏素材一致。
基础音效最初制作时移除了多余的首尾静音，加入 2 ms 淡入淡出，并以峰值不超过 0.89、有效片段 RMS 不超过 0.13 的方式统一音量。

| 原始文件名 | 正式文件名（不含扩展名） | 使用场景 |
| --- | --- | --- |
| 发牌1.mp3 | card-deal-01 | 每张牌随机选两种之一 |
| 发牌2.mp3 | card-deal-02 | 每张牌随机选两种之一 |
| 弃牌.mp3 | card-fold | 确认弃牌 |
| 过牌.mp3 | table-check | 确认过牌，完整播放原有敲击节奏 |
| 推筹码下注.mp3 | chips-push | 跟注、下注、加注、全下、大小盲投放 |
| 预下注少筹码.mp3 | chips-stage-small | 其余预下注放置 |
| 预下注多筹码.mp3 | chips-stage-large | 预下注金额 > 当前底池，且金额 > 100 |
| ALLinMale1.wav | all-in-male-01 | 本手首位全下的男性角色 |
| ALLinMale2.wav | all-in-male-02 | 本手后续全下的男性角色 |
| ALLinFemale1.wav | all-in-female-01 | 本手首位全下的女性角色 |
| ALLinFemale2.wav | all-in-female-02 | 本手后续全下的女性角色 |

全下时同时播放推筹码声和对应的角色语音。每手重新计算全下顺序，跟注用完筹码也算全下。
预下注只在选额后松手放置时播放，拖动滑杆预览、取消或全部收回不播放。
游戏通过 `client/audio-bank.js` 一次加载音效数据，不单独请求 WAV URL，避免 IDM 等下载管理器拦截。
替换 `client/assets/audio/` 中的 WAV 后，双击游戏目录下的 `更新音频.cmd`，再刷新游戏页面。手机版打包会自动更新音效数据。
音效加载后复用解码结果，失败也不会随点击反复请求；浏览器首次鼠标、触屏或键盘操作解锁播放。

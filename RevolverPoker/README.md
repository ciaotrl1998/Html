# RevolverPoker

手机竖屏、第一人称 3D 西部酒馆中的标准无限注德州扑克。每桌 8 个座位，2–8 人开场，支持朋友联机及 AI 对手，使用同一套入座流程。

## 启动

需要 Node.js 22 或更新版本。Windows 可直接双击目录中的 **启动游戏.cmd**。首次启动会安装项目依赖；安装后运行时不依赖外部 CDN。

也可在 PowerShell 7 中执行：

```pwsh
Set-Location F:\Html\RevolverPoker
npm ci --cache .cache/npm
npm start
```

打开 [http://localhost:3088](http://localhost:3088)。首次启动的服务窗口需要保持运行；按 Ctrl+C 停止。重复启动时，若游戏服务已运行，会直接提示现有服务地址，不会再次占用端口或中断房间。若端口被其他程序占用，可设置 `$env:PORT=3089` 后执行 `npm start`。

## 场景编辑器

双击 **打开场景编辑器.cmd**，会自动启动本机编辑服务并打开 [场景编辑器](http://127.0.0.1:3090/editor)，直接进入酒馆场景，不需要创建房间。也可运行 `npm run editor` 后访问该地址。服务重复打开会复用，无需关闭正在运行的游戏。

- 点击画面中的物件或左侧列表选择；列表可搜索、按分类筛选。公共牌和自己的底牌可以整组编辑，也可单独调整。
- 搜索 **筹码堆** 可调整自己或其他座位的筹码，编辑器使用与游戏一致的交互筹码模型；搜索 **预下注** 可独立调整桌前待抛出的筹码。搜索 **弃牌位置** 可逐座位调整其他玩家弃牌后的落点，选择时自动开启 **弃牌预览**，游戏中的弃牌动画会落在保存的位置。预览不影响真实对局。
- 搜索 **底池** 可调整桌面底池模型的位置、旋转和缩放。所有玩家的筹码堆按实际余额显示；盲注、底注、跟注、加注和全下的筹码会移入底池并留在桌上，跨轮累计，结算时按服务器的主池、边池和退款结果移回相应玩家。断线重连直接恢复当前筹码，不重复下注或派奖。
- **W** 移动、**E** 旋转、**R** 缩放，使用标准红 / 绿 / 蓝三轴操作柄；支持世界 / 局部坐标、吸附和数值输入，旋转数值单位为度。
- 左键拖动空白处环绕，中键或右键拖动平移，滚轮缩放；**F** 聚焦选中物件。可切换总览、玩家视角和俯视。房屋外壳默认隐藏方便编辑，可随时开启；该显示选项不影响游戏。
- **Ctrl+Z** 撤销、**Ctrl+Shift+Z / Ctrl+Y** 重做；右侧可重置选中物件。“恢复默认”重置整个编辑场景，之后点击 **保存并应用** 才会同步到游戏。
- **保存并应用 / Ctrl+S** 写入项目的 `client/scene-layout.js`，当前游戏页面约 3 秒内自动加载；此前一直开着的旧版游戏首次需刷新一次。重新打开编辑器和重启游戏服务后仍会保留。
- 视口上方的 **摄像机** 是预览开关，开启后右下角始终显示竖屏画面，选择其他物件时也会保留；开关状态会记住。预览窗口内可切换“玩家视角 / 公共牌视角”，点击其中的“编辑”选中对应摄像机，也可从列表的“摄像机”分类选择。
- **玩家视角摄像机** 与 **公共牌查看摄像机** 都支持移动轴、旋转环、精确数值、FOV、近 / 远裁剪、视锥、撤销 / 重做、单独重置及保存。公共牌摄像机随公共牌组移动，可独立调整并用于编辑器参考预览；游戏按住公共牌时立起牌张，摄像机保持不动。开始牌局后才使用玩家摄像机；等待开局时入座保持俯视。松开底牌只盖牌并保留当时视角。
- **从摄像机查看 / 玩家视角 / 公共牌视角** 实时跟随对应摄像机；回到总览或俯视可继续环绕和操作摄像机轴。**对齐当前视图** 把选中摄像机的位置、朝向与 FOV 对齐当前自由编辑视图。**摊牌预览** 可查看结算时头顶手牌和牌型的效果，不改变真实对局。

编辑器使用独立的八人示例牌局，不会修改真实房间、底牌或筹码。预览中的底牌翻开以便调整。游戏中的人物呼吸、发牌动画、座位状态和按住看牌继续正常运行。编辑服务仅监听本机回环地址，文件保存只接受本机同源请求。多人游戏服务器向所有玩家提供同一份已保存布局。

## 如何开局

1. 输入昵称，点击“开一张牌桌”；朋友输入六位房间码加入同一个服务上的房间。
2. 每个人点击“开放”空座入座，镜头切到自己的第一人称位置。
3. 房主坐下后，点击其他空座切换“开放 / AI”。AI 座位再点一次恢复开放，已坐下的真人不能被替换。
   等待开局时，再次点击自己的角色、座位或头顶标签即可起身，座位恢复开放；也可重新选择空座入座。
4. 房主在“牌桌规则”里设置初始筹码、大小盲、前注、升盲、行动时间与电脑难度。
5. 至少两位真人或 AI 入座后，房主点击“开始牌局”。无需坐满，也无需另选单人或联机模式。

一人游玩时，只需把至少一个其他座位设为 AI。开场后锁定参赛名单，开放空座留给下一场；每手之间继承筹码，本场不补码。所有人筹码归零淘汰至最后一位胜者，或由房主选择“本手结束后结算本场”。结算后“再开一场”保留座位配置。

## 手机与朋友联机

### 同一网络

电脑启动服务后，终端会显示一个或多个 `LAN: http://地址:3088`。让手机与电脑连到同一 Wi-Fi，访问电脑对应的局域网地址，然后使用同一房间码。

`localhost` 只表示当前设备，手机应访问电脑的 LAN 地址。如果连接失败，检查设备是否在同一网络、路由器是否启用访客隔离，以及 Windows 防火墙是否允许该 Node.js 服务在专用网络接入。

### 异地联机

房间码不会自动建立公网连接。异地朋友需要访问同一个已部署的游戏服务。本项目包含 Node.js HTTP + WebSocket 服务，可在支持持续运行 Node.js 的服务器上启动，再通过反向代理提供 HTTPS/WSS。静态网站托管不能独立承载本项目的牌局服务。

例如服务器设置 `PORT=3088`，使用进程管理器运行 `node server/index.js`，域名反向代理配置如下（将域名和证书替换为自己的）：

```nginx
location / {
    proxy_pass http://127.0.0.1:3088;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 90s;
}
```

客户端会自动使用当前网页的域名和 HTTP/HTTPS 对应的 WS/WSS，无需修改代码。本次交付仅在本机运行，未进行公网部署。

## 规则与操作

- 标准 52 张牌，每人两张底牌，五张公共牌，取最佳五张比较。
- 每手结算后，角色头顶的 3D 广告牌展示两张手牌缩略图和最终最佳牌型名称，不展示姓名与筹码。胜利玩家的两张牌带金色外描边，上方金色“WIN”每秒循环从 100% 放大到 120% 再缩回，手牌和牌型名称保持不动；平分底池及边池获胜者也会标记。弃牌 / 未摊牌 / 未公开的底牌使用牌背和对应状态，不泄露隐藏信息。下一手开始后恢复正常信息。
- 对局使用桌面手势，已移除底部弃牌、跟注、加注按钮及加注弹窗。单击自己的筹码堆，将跟注所需筹码移到桌前；按住桌前筹码向前拖出并松开才提交跟注。
- 按下自己的筹码堆立即显示竖向滑杆，无需先拖动；快速单击松开预备跟注，按住或直接拖动即可选额，上拉增加、下拉减少，顶端为允许的 ALL IN。松开后将选中的本次投入放到桌前，并显示准确金额。提交前可再次长按重新选择，按差额移入筹码或退回筹码堆；单个筹码标有面值。单击桌前预下筹码可全部收回筹码堆，金额标记随之消失；横向拖动或取消手势不会误提交。预下金额不修改服务端余额，前拖桌前筹码并松开才提交下注或加注，已提交的下注不可收回。
- 按住自己的手牌向桌面中央前拖并松开即可弃牌；按住不前拖仍可翻牌查看。连续点击两次桌面过牌，有跟注欠额时不会误触过牌。筹码、手牌手势会暂停视角拖动，空白桌面拖动仍可转向。
- 预下金额随回合、手数、房间、连接状态变化自动清空。提交中的同一手势不会重复下注；不足最小加注额时仅允许合法的短筹码全下。
- 正确处理双人桌、踢脚牌、A2345、边池、平分余数、未匹配下注返还及不足额全下后的加注权。
- 大盲为小盲两倍；可固定盲注，或每 5 / 10 / 20 手翻倍；前注为每人每手固定数值。
- 公共牌与底牌均为带圆角、纸张厚度、正反面和阴影的真实 3D 模型；公共牌铺在桌面，自己的底牌默认扣在两臂之间的近身桌面，筹码移到旁边留出空间。牌面随服务器状态更新，包含发牌、翻牌和弃牌动作。
- 直接按住底牌模型，底牌原地翻开，摄像机保持不动；松开后只盖回牌。按住公共牌模型会立起公共牌并朝向玩家，松开后放回。看牌期间暂停鼠标或触屏转向。底部仅保留筹码、行动状态和计时，不显示操作按钮。
- 松开鼠标或手指、操作取消、窗口失焦或切入后台时，都会结束看牌并盖回底牌。转头时牌张留在桌面，不跟随屏幕移动。点击对手显示其公开信息。
- 等待开局时保持俯视，入座只添加角色，不旋转牌桌或切换摄像机；按住拖动仅带来小幅平滑转动，接近边缘时阻力增大，水平约 ±5.7°、垂直约 ±3.2°，移出画面后平滑回正。开始牌局后，已入座玩家才切换到保存的第一人称摄像机，重新开局回到等待阶段时恢复俯视。
- 电脑端按住鼠标左键拖动转向，触屏设备按住画面拖动转向；两端采用相同的拖动逻辑，松开后停止转向，不锁定鼠标指针。方向键也可转向，右上角 ↺ 或 Home 恢复当前阶段的默认视角；俯视阶段的触屏与键盘操作同样受旋转范围限制。
- 对局中轮到其他玩家或 AI 行动时，镜头会在前 0.6 秒逐渐加速、后 0.4 秒逐渐减速，平滑起步并在 1 秒时对准该角色、停止转动，摄像机位置保持不动。按住拖动或使用方向键会立即暂停自动对准，停止操作 1 秒后从当前视角重新开始这段对准过程；看牌、打开菜单、窗口失焦及牌局结束时暂停。轮到自己时，使用相同的 1 秒加速、减速曲线恢复到保存的玩家摄像机初始朝向；手动拖动同样可打断，停止操作 1 秒后恢复。
- 人物标签使用 3D 场景内的广告牌，挂在角色头顶，始终面向摄像机；转头时与人物同步移出或进入视野。点击标签、人物或空椅即可操作，拖动不会触发入座或切换 AI。
- 菜单可查看牌型、切换合成提示音或省电画质。声音初始关闭。
- 房主可随时在右上角菜单选择“关闭房间并返回主菜单”，立即停止当前牌局并解散房间；其他玩家会收到通知并一起返回主菜单，无需等本手结算。
- 多人局行动可设 15 / 30 / 60 秒；仅一名真人的桌子另可不限时。
- 超时：可过牌则过牌，否则弃牌；断线不会自动跟注或全下。
- 刷新页面后凭当前标签页内的匿名会话重连。昵称不是身份凭证；每个不同浏览器标签页可使用独立身份。
- 房主关闭浏览器时，可由其他在线真人接任房主；关闭运行服务的终端会中断整个游戏。

## 实现与验证

客户端：Three.js、DOM/CSS、原生 WebSocket。场景、人物、桌面、道具与手部均为程序生成 3D 模型及本地纹理，没有运行时外部美术依赖。

服务端：Node.js、ws，统一管理牌堆、行动、计时、边池与筹码。服务器不会向玩家或 AI 下发其他人的隐藏底牌。洗牌使用 `crypto.randomInt`，AI 只接收自己席位可见的信息。

运行自动化测试：

```pwsh
npm test
```

测试覆盖规则边界、1,000 次随机牌局、真实 WebSocket 的八人入座与抢座、权限、隐藏底牌、重复行动、会话重连，以及 1 真人 + 7 AI 的结算与重开。

当前运行边界：

- 房间保存在服务内存中；服务重启不会恢复之前的牌局。
- 3D 场景需要 WebGL 2；不支持时给出提示，规则与牌桌界面仍可操作。
- 模型为首版风格化程序模型，牌张已有独立的 3D 发牌 / 翻牌动画，角色尚未使用精细骨骼发牌动画。
- 已进行桌面浏览器的手机尺寸检查；实际手机性能仍需真机验证。

项目结构：`client/` 场景及界面，`server/` 联机和 AI，`shared/` 规则，`tests/` 自动验证。原始需求与策划见同目录的《游戏策划.md》。
